"# Design-patterns" 

Creational Patterns → Object kaise create karein?
===================
1. Factory Pattern

Object ko directly create karne ke bajay, object creation ki responsibility Factory ko dena.

Keyword: Create

2. Builder Pattern

Complex object ko step-by-step create karna, especially jab bahut saare optional fields ho.

Keyword: Build()

3. Prototype Pattern

Existing object ki copy/clone karke naya object create karna.

Keyword: Clone / Copy

4. Singleton Design Pattern

Singleton Pattern ensure karta hai ki kisi class ka application mein sirf ek hi object (instance) ho aur us object ko globally access kiya ja sake.

================================================================
Structural Design Patterns

Simple definition:

Structural Design Patterns batate hain ki classes aur objects ko kaise combine/connect karein, taaki system flexible aur easy to maintain rahe.

1. Decorator Design Pattern
Decorator Pattern existing object mein bina uski class change kiye, dynamically new behavior/functionality add karta hai.

2. Proxy Design Pattern
Proxy Pattern original object ke liye ek substitute/representative provide karta hai aur uske access ko control karta hai.

3. Facade Design Pattern
Facade Pattern complex system ke multiple classes/methods ke liye ek simple interface provide karta hai.


4. Flyweight Design Pattern
Flyweight Pattern common/reusable data ko share karke memory usage reduce karta hai.
